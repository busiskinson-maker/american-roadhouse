# Antislop Audit 001

Date: 2026-10-20  
Scope: Static review of the existing multipage site and its local assets. No website files were changed.

## Findings

### 1. [HIGH] Em dashes appear throughout visible copy (R-02)

The HTML uses `&mdash;` in user-facing text across the homepage and interior pages, which renders as the prohibited em dash. Example: `index.html:92`.

### 2. [HIGH] Review score and count have no cited source (R-17)

The site repeats a 4.6/5 rating and 40 reviews in its trust bar, About page, and structured data without identifying a source, so visitors cannot verify the claim. Examples: `index.html:36-38`, `about.html:103`.

### 3. [HIGH] Footer links point to the current page (R-26)

Facebook, Instagram, Privacy Policy, and Terms of Use use `href="#"` on every page, so these controls do not take visitors to their advertised destinations. Example: `index.html:459-476`.

### 4. [HIGH] Placeholder reviews are presented inside testimonial cards (R-38)

The homepage places “Guest Name” and copy announcing that review text is still to be added under “What Our Guests Say”; although each card says “Placeholder,” the section still presents testimonial-shaped content with no real source. `index.html:325-350`.

## Asset inspection

The site has existing venue and roof-deck photography, room photography, food photography, menu boards, and brand artwork. The current page markup already uses relevant local images for its hero, room, food, venue, menu, and gallery sections; keep those local assets as the starting point for future design work.

The files called `assets/brand/logo-mark.png`, `logo-full.jpg`, and `opening-soon-source.jpg` show the same square “OPENING SOON” burger poster, rather than a clean standalone logo. The current header and footer render `logo-mark.png` at 34px and label it as the logo. Treat this artwork as a promotional poster; use the existing text wordmark separately unless an actual logo file is supplied.
